# WDAI 

**Repository of projects for the WDAI (Introduction to Web Applications) course**

_This repository contains sample projects developed during the WDAI (Introduction to Web Applications) course, which is a 3rd-semester course in the Computer Science program at AGH University of Science and Technology in Krakow, Poland._

---

## 1. [Strona_projekt](Strona_projekt/index.html)

The first project written during the classes. 
We were tasked with creating a website on any topic 
without using frameworks. 
The website was supposed to include the following elements:
* The page has a layout.
* There are subpages - at least 3.
* The page contains images, videos, or audio.
* There is a form on the page.
* CSS was used.
* Use of JavaScript
* Form data validation
* Public availability
* Responsive design
* Visual design
